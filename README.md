# Medellín Te Orienta

Aplicación web informativa para orientar a habitantes de Medellín sobre canales de atención y denuncia.

## Publicación

Este sitio está preparado para GitHub Pages. El archivo principal es `index.html`.

## Uso

Abre el sitio y selecciona el tipo de incidente para consultar pasos y canales oficiales. En emergencias, llama al 123.

Proyecto independiente; no reemplaza los canales oficiales de las autoridades.
